# Sema

Sema version 0 reads Markdown into a typed document tree and prints Markdown from that tree. This repository begins with the reviewed contract only; independent implementations start from separate branches.

Vision source: `psyche-belief` revision `738727d23ec9e9cc6f37b018f428eee5c6cee057`, `vision/sema-v0.md`.

## Status: prototype, incomplete

- The Markdown codec is comrak 0.59.0, both ways (Fable order). comrak reads
  the text into its CommonMark tree, `src/compose.rs` walks that tree into the
  Document, and `src/print.rs` builds the tree from a Document for comrak to
  print; `src/commonmark.rs` configures both directions in one place. No comrak
  type is in the schema. What the Document has a place for is read whichever
  way it is written: a setext heading, a `*` list, a tilde or indented fence.
  What it has no place for is `Unsupported`: an ordered list, a thematic break,
  an HTML block, an image, a hard line break, a link title, an aligned table,
  a list item of more than one block, a heading inside a list or a quote, inline HTML (a tag written in prose,
  `vision:<topic>`, among it). An unclosed fence is code to the end of the
  text. The
  libraries measured against the belief corpus, and the per-module table, are
  in `measure/round-trip.md`.
- Depth is the nesting, read relative: the shallowest heading's level is the top
  and each deeper level a child; a heading skipping a level is `Unsupported`. The print is canonical, top sections at `#`, so a
  module opening at `##` prints back one level up (Fable ruling, inferred,
  pending the living).
- Fence spellings are the tags the modules write: `ethos`, `datom`, `rust`,
  `nix`, `sh` (Shell), `ini`, `toml`, `mermaid`, and no tag for Plain.
- A Target is a Url and nothing else in version 0: every link target,
  anchors included, is read and printed as the string written (Fable ruling,
  edition 9). Place is the Sema address yielded by search and edit, and is
  never read out of Markdown, so `print.[ Markdown ]` is total.
- A whole module is a `ModuleText`, composed into `Module.{ FrontMatter Document }`
  and printed back into a `ModuleText` (`sema module <path>`; Fable rulings,
  inferred, pending the living). The front matter is read as the three
  fields of FrontMatter, in any order, and printed canonically in the type's
  order; the text after the closing delimiter line is handed to Markdown. A
  description may be plain, double-quoted or single-quoted, and prints plain
  when the plain form reads back the same, double-quoted otherwise. A
  missing or empty field is `Missing`. The dependencies are read as a flow
  sequence or a block sequence and printed as a flow sequence; a name is a
  plain YAML scalar as written, `intent:energy` among them; any other front-matter line is
  `Unsupported`, carrying that line. Source bytes are kept only when the
  source is already canonical.
- Reading refuses with `ReadRefusal.{ Line Problem }` as ruled:
  `Unsupported`, a construct the Document has no place for, carrying the
  line as written, or `Missing` a front field; a front matter with no closing
  delimiter is `Unsupported` at its opening line. A Document
  alone still refuses front matter.
- `Structural` implements `outline`, `code`, `references` and `search` by hand.
  `edit` is not implemented: `Mismatch.{ Place Expected.Block Found.Block }` names
  a Found block, and no rule yet says which block is found when no block at
  the place equals Expected.
- Every type and every trait is declared in `ethos/` and generated by
  ethos-zero 22.0.0, pinned as a flake input: the contract in `document`,
  `markdown` and `module`, the lane's working types and helper traits in
  `reading`. Generation is the flake's `generated` derivation, and the crate
  is built from the hand-written source with its output beside it; nothing
  generated is kept in the repository. The hand-written Rust is trait bodies,
  checked by `no-hand-written-declarations`. comrak's types bear lane traits
  and appear in no signature. A `datom` feature compiles the datom derives.
- `edit` is implemented: a Place names the section with those titles, the
  block at the place. Insert appends to it, or to the document at the root;
  Replace and Remove act on it when it is the expected block, and are
  refused with `Mismatch` naming it as Found when it is not. A Place with no
  block, for any edit, is `NoSuchPlace`; a refused edit leaves the document
  as it was.
- `measure/` is the codec study at `6121274`, built against the hand-written
  types; it is not rebuilt against the generated ones, and does not build
  without them.
